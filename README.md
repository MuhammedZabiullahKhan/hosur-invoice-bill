### 🚀 Deploy to GitHub Pages (Free)

1. Create GitHub repository: `hosur-invoice-bill`
2. Upload all files (index.html, app.js, sync.js, etc.)
3. Go to Settings > Pages > Branch: main > Save
4. Your app live at: `https://YOUR_USERNAME.github.io/hosur-invoice-bill`
